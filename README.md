# 掌舵 · AgentDeck

Android 上的 SSH Agent 工作台：连接自己的电脑，操作 Codex，阅读已有会话，并查看项目的 Git Changes 与 Graph。Claude Code 和 G2 随后接入。

当前已实现 Codex 首版工作台：跨主机项目首页、多主机、SSH 密码／生成或导入密钥登录、加密凭据、原生历史与正文搜索、新建／恢复会话、流式回复、审批／取消、断线事件恢复、后台通知、图片／分享和电脑端语音转文字。Git 支持 Changes、Diff、真实提交 DAG、分页和合并父提交选择。Graph 使用紧凑单行标题与相对时间，长标题省略，点击行内展开完整说明、引用和文件变更。

Android 工程位于根目录，应用模块为 `app/`，application ID 为 `com.worldcopy.agentdeck`。在 Android Studio 中打开根目录，或用 `./gradlew :app:assembleDebug` 构建。电脑服务位于 `host-service/`，仅监听回环地址，经 SSH 隧道访问。

模拟器到本机 Mac 的 SSH、真实 Codex API 文字／图片、审批／取消、断线恢复和后台通知已实测；详情见 [验证记录](docs/validation/codex-workbench.md)。开发配置以 Codex CLI 0.159.2、Node.js 24+ 为基准，手机不保存模型 API key。

## 启动使用

1. 电脑启用 SSH，安装并配置 Codex CLI。电脑端运行 `cd host-service && npm ci && npm run build && npm start`。
2. 手机右上角三个点菜单进入“密钥”，点“创建密钥”选择 Ed25519、RSA（3072 位）或 ECDSA（NIST P-256），将公钥配置到目标账号 `~/.ssh/authorized_keys`；已有电脑密钥可点“导入已有密钥”，选择文件或粘贴私钥，支持 OpenSSH／PEM 的 Ed25519、RSA 和 ECDSA（NIST P-256／P-384／P-521）。公钥可自动提取，或同时选择 `.pub` 核对；加密私钥需在导入时输入口令。也可以选择密码登录。
3. 在项目页“同步项目”左侧点绿色“添加主机”，填写 SSH 地址、账号和认证方式。App 通过已认证的 SSH 自动读取电脑 `~/.agentdeck/token`，无需手动填写服务令牌；自定义服务目录和端口在“高级服务设置”中配置，端口默认 `4317`。模拟器连接本机 Mac 使用 `10.0.2.2`；真机使用电脑可达地址。
   创建相似主机时，可长按项目页中的已有主机，选择“克隆”，修改名称、地址、端口、账号和认证方式后保存。密钥登录沿用所选密钥；密码登录留空沿用原密码，也可填写新密码。新主机首次连接会重新确认 SSH 主机身份并自动获取服务令牌。
4. 打开 App 时并行连接已配置主机并读取最近一页会话摘要，最多同时加载 10 台；超过上限的主机排队，已有主机完成或失败后接替加载。先完成的主机可立即打开。从后台回到前台复用已有连接、当前会话和草稿。电脑端持续维护完整的未归档会话摘要目录，约每 2 秒检查新近变更；新对话首次落盘后会自动出现在已连接手机的列表中，改名和归档也会同步。手机重连补齐离线期间的目录变更。“同步项目”也按此并发上限手动刷新最近摘要，主机展开后的“加载更早的项目与对话”按需继续分页，打开对话时才读取正文。首次连接或主机身份变化时，依次核对主机身份，确认后自动继续同步；连接失败会显示错误并保留缓存，其他主机继续同步。列表分为“主机 → 项目 → 对话”：主机和项目默认折叠，先展开主机查看项目，再展开项目选择对话。主机显示已加载的项目与对话数，连接／同步时转圈，失败时显示警告三角形；展开主机可查看详情与重试。项目按所属主机与文件夹完整路径区分；收起主机也会收起其项目。
5. 在项目中打开或新建会话；首次使用一个还没有对话的文件夹，可长按主机选择“进入工作台”，输入绝对路径创建。长按菜单还提供连接、重连、编辑、克隆和删除；“重连”会重新建立 SSH 与电脑服务连接。首页直接显示项目，右上角三个点菜单进入“密钥”；“掌舵”右侧的铃铛进入待处理事项，并显示待处理数量。
6. 默认启用“保持连接”，连接通过前台服务在后台继续接收回复，首次配置主机时可允许通知。可在首页关闭后台连接，或从常驻通知断开。系统强制停止、省电限制、网络中断或 Android 的后台 dataSync 服务时限仍可能中断连接；回到前台会恢复连接。电脑端服务应常驻；macOS／Ubuntu 常驻安装与语音设置见 [电脑服务指南](host-service/README.md)。

会话输入框上方以单行文字显示当前模型、思考强度与权限，点击这行文字即可选择电脑 Codex 提供的模型（如 GPT-6 Astra、GPT-6.1 Sol）与支持的思考强度。思考强度使用从低到高的滑动条，英文档位依次为 low、medium、high、extreme high、max、ultra，仅提供当前模型支持的档位；拖到 ultra 时滑块、轨道和当前值标签使用独立蓝色强调。权限使用横向滑动条，从左至右为只读／未信任／请求批准／不请求批准／完全访问，拖动或点按轨道选择档位，当前权限及其说明随之更新。完全访问使用红色文字与滑块，轨道显示缓慢滚动的红黄警示斜纹；系统关闭动画时保持静态。空闲会话可保存设置，下一轮生效，并在重连及电脑服务重启后保留。其他来源的 Codex 历史会话也可直接保存设置或点击“继续对话”：App 会先恢复原会话，再保存设置或发送消息，保留原会话 ID 和上下文。仅浏览历史不会恢复执行；若电脑报告会话仍在运行，则显示原因并保留草稿。此功能沿用电脑端的恢复与执行设置接口。

若检测到其他端的 Active Writer，输入区仅显示“接管会话”。点击后尝试取得原会话写入权：成功则恢复设置、输入和附件，并显示 Fork；仍被占用则提示“有其他用户正在使用”，并提供 Fork。Fork 保留已存历史、创建独立会话，原会话和草稿保留。

打开项目对话后默认定位到最新消息末尾，包括离线缓存。停留在底部时跟随新回复；向上翻阅历史时保持阅读位置，可点“查看最新消息”回到底部。

Agent 的说明文字保持可见；执行活动默认显示为无边框的单行灰色摘要，运行中将状态与摘要合并，完成后只保留摘要。点击摘要查看简短指令列表，再点具体指令查看命令及输出。

消息正文支持 CommonMark 与常用 GFM 格式：标题、粗体／斜体、删除线、嵌套列表、任务列表、引用、分隔线、表格、代码块及链接。宽表格和长代码可横向滚动，代码可复制。点击回答中的文件链接或图片引用，再点“下载文件”，选择手机保存位置；绝对路径、相对项目路径及带行号的文件引用均可下载。网页链接交给浏览器打开。下载需要更新电脑端服务。

图片会缩放并规范方向后上传。录音最长两分钟，在电脑本地转写，回到手机草稿供确认，随后手动发送。文字／图片分享入口也先进入选定会话的草稿。
