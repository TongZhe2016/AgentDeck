# 手机工作台交互与连接改进

日期：2026-10-08。

## 执行展示

Agent 的过程说明和最终回复直接显示。连续工具活动默认折叠为状态与最新一条摘要；首次展开显示简短指令列表，再点具体条目显示命令、文件修改或工具参数与输出。每段工具活动按轮次及相邻 Agent 消息分组，流式更新不改变展开状态。阅读缓存保留分组、摘要和详情。

已通过 Android debug 构建与单元测试，涵盖 Agent 消息保留、分段、跨轮次边界和摘要截断。API 36 模拟器 `emulator-5554` 已通过两次点击的展开层级测试。


## 设置与加载

输入区显示模型、思考强度和权限（只读、请求批准、未信任、不请求批准、完全访问），底部面板使用 `model/list` 返回的模型与支持的强度。设置经服务端验证并保存至 `session_settings`，`turn/start` 显式传递模型、强度和权限。设置接口无需读取或恢复历史，因此适用于尚无历史文件的新建空会话。新建／恢复使用 Codex 回传的实际设置。执行过程中暂停修改。

连接时读取一页 40 条摘要，不循环拉完全部历史；首页保留已有缓存，显式加载更多时才读取下一页。服务端 `thread/list` 使用 `useStateDbOnly`，并仅投影摘要字段。正文仍在打开选中会话时分页读取。恢复线程使用 `excludeTurns`。

默认启用后台前台服务，设置可持久保存。返回前台跳过已有在线／正在恢复的事件连接；SSE 建立后即显示在线。摘要及消息缓存写入移到 IO 线程，历史条目解析移到 Default 线程。

服务端 10 项测试已通过，覆盖模型目录分页、设置校验及持久化、已加载／重启后恢复的执行参数、列表不读取正文及既有审批／去重行为。本机 Codex CLI 0.159.2 的真实 `model/list` 与 `config/read` 调用成功，目录包含 GPT-6 Astra、GPT-6.1 Sol 及各自强度。另外在真实 Codex 的临时会话上验证了四种权限组合的实际回传结果。新建临时空会话通过实际 HTTP 设置接口成功保存 Astra／max／不请求批准；未读取或恢复其历史。本轮未发送收费模型请求。

Android debug 构建、单元测试、lint 和设备测试 APK 编译已通过。设备用合成回环 HTTP/SSE 验证后台接收、回前台保留会话／草稿／同一事件流和按需分页；已通过：切出／返回前台保持 1 次 SSE 建连、1 次列表请求、1 次选中会话正文请求；后台收到新消息，返回时会话与草稿保留；主动加载更多后列表请求才增加到 2 次。

物理手机的厂商省电策略、切网及长时间锁屏仍需实机验收。保留 Android dataSync 前台服务类型，因此受 Android 系统后台运行时限约束；不承诺系统强停或网络不可达时保持连接。
