# SSH 自动获取电脑服务令牌

验证日期：2026-10-01。环境：Android API 36 ARM64 模拟器，Ubuntu 20.04 远端既有 AgentDeck 用户服务。

## 行为

手机主机设置只需填写 SSH 地址、账号和认证方式。连接服务时，通过已认证 SSH 读取 `~/.agentdeck/token`，保存到 Android 加密凭据库，并自动携带到 HTTP／SSE 请求。每次重连重新读取；事件流认证失效时重新建立 SSH 并获取令牌，健康请求通过后沿用事件游标继续接收。

主机设置不再提供手工令牌字段。“高级服务设置”可配置端口和数据目录，以连接使用自定义 `AGENTDECK_DATA_DIR` 的服务。电脑服务仍需事先安装并启动，SSH 账号须有该目录读取权限。
