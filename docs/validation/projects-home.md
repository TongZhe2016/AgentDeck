# 跨主机项目首页验证

日期：2026-09-30；Android API 36 ARM64 模拟器。

原首页按主机列出，进入工作台后平铺该主机的会话。现在默认首页为项目列表，以主机 ID 和会话 cwd 的完整路径分组，按最近会话更新时间排序。卡片显示文件夹名、主机名、路径和对话数；首次进入及返回项目首页时默认折叠，展开后才渲染会话行。相同名字的文件夹不会合并，不同主机上相同路径的文件夹也不会合并。

项目来自原生会话所在的文件夹，不扫描电脑整个文件系统。“同步项目”连接已配置主机并遍历会话分页；可以单独同步某台主机或取消读取。未连接时展示上次缓存并注明同步状态。标题搜索结果单独显示，不替换项目索引。新增会话会更新并保存首页索引。新文件夹的首次会话通过主机工作台创建。

`ProjectHomeTest` 使用隔离数据验证：

- 第一页 40 条、第二页包含重复项及旧项目，读取后得到 41 个独立会话；同名目录、同路径不同主机保持三个独立项目。
- 两台主机含相同会话 ID，首页初始不显示会话行。展开指定项目只展示该主机的会话，收起隐藏；点击会话显示正确主机的缓存内容。
- 从对话返回项目首页，恢复折叠的项目列表；打开项目的新建入口保留所选目录，只显示此项目会话，离线时禁用新建。测试结束清理测试主机和缓存。

Android debug 构建、测试 APK 构建及 lint 通过。最终模拟器两项测试的 TestRunner 记录为 2 tests, 0 failed；ADB 的结果回传曾遇到模拟器 Binder watcher 故障，依据设备内的完成记录判断结果。测试未调用真实模型，也没有修改服务器部署。
