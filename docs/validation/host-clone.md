# 主机配置克隆

2026-10-01：主机三个点菜单新增“克隆”，进入预填表单，保存后创建独立主机。可修改名称、SSH 地址／端口、用户名、认证方式、所选密钥和高级服务设置。

密码登录留空沿用原密码，填写新密码时使用新值；密钥登录引用已有密钥。新主机生成独立 ID，首次连接重新确认主机身份并通过 SSH 获取自己的服务令牌。

## 验证

- `:app:assembleDebug`、`:app:assembleDebugAndroidTest`、`:app:lintDebug` 通过。
- Android API 36 ARM64 模拟器的 `HostCloneTest` 两项通过：
  - 取消克隆不增加主机；修改名称、地址、端口、用户名和服务端口后保存，重读存储验证新配置及沿用密码，原主机配置与令牌保持完整，新主机尚无服务令牌或已信任主机公钥。
  - 密钥克隆沿用密钥选择；改为密码登录时要求输入密码，保存后的认证方式与凭据正确，原主机保持完整。

测试仅使用合成主机和凭据，结束后删除测试主机与密钥。克隆不自动连接电脑，本次无需调用 SSH 或模型 API。构建与设备测试日志保留在 `.local/ui-refresh/`。

物理手机 USB 更新暂被 vivo 系统拒绝（`INSTALL_FAILED_ABORTED: User rejected permissions`）；需在手机允许安装后重试。
