# AI 回复处分叉（2026-10-16）

每个已结束轮次的最后一条 AI 回复下方显示“Fork 新对话”。点击后通过电脑端原生 `thread/fork` 和 `lastTurnId` 创建独立会话，只保留截至所选轮次（含该轮）的上下文，打开新会话供继续输入。原会话、后续轮次和原草稿保留；新会话使用自己的草稿。执行中的轮次不显示入口，离线及请求期间按钮禁用。失败显示现有错误提示，保留原会话供重试。

Codex 原生边界为轮次，执行中的说明文字不单独提供分叉按钮。既有接管流程中的 Fork 继续复制全部已存历史。需要同时更新 Android APK 与电脑服务，原生接口已在 Codex 0.161.0 验证。

验证结果：

- `npm --prefix host-service test`：18 项通过，覆盖指定轮次传递、空轮次拒绝、既有全历史 Fork 和接管。
- Android debug APK、设备测试 APK、单元测试及 lint 通过；lint 为 0 errors，36 项现有 warnings。
- API 36 ARM64 模拟器 `emulator-5554`：`MessageForkTest` 两项与 `ActiveWriterTest` 三项通过。覆盖较早轮次分叉、进行中的回复及过程说明无入口、独立历史、原草稿恢复、失败重试与既有接管行为。追加验证已结束回复的事件重放不会清除 Fork 入口。
- 约 376dp 窄屏浅色竖屏、深色横屏加两倍字体及关闭动画：两组各两项设备测试通过，截图确认 Fork 按钮可见并可操作。复测中截图辅助代码曾遇到 UI Automation 连接失败，已改用 Compose 截图；模拟器冷启动后直接运行 instrumentation 得到完整通过结果。
- 真实 Codex 0.161.0 + HTTP API：在隔离 Codex home 中创建两轮合成历史，从第一轮分叉后新会话仅含第一轮，原会话仍含两轮；返回独立 ID、原会话来源和 managed 状态。模型端点为本地 503 合成服务，未调用收费模型；该项验证原生历史截断，AI 回复按钮行为由设备测试验证。
