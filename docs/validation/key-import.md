# 已有 SSH 密钥导入

验证日期：2026-10-01。Android API 36 ARM64 模拟器，真实 Ubuntu SSH 服务。

## 实现

“密钥 → 导入已有密钥”支持文件选择和文本粘贴，接受 OpenSSH／PEM（含 PKCS#8）私钥，支持 Ed25519、RSA 和 SSH 使用的 NIST ECDSA 曲线。公钥从私钥提取；可选的 `.pub` 内容须与私钥匹配，注释不参与比较。

OpenSSH 由现有 SSHJ 解析，PEM 由 Bouncy Castle 解析。输入的文件口令仅在导入时解密，私钥按既有 Android Keystore 凭据库加密保存，不保存导入口令。密钥元数据记录算法，以便进程重启后恢复。以前生成的 Ed25519 记录继续使用默认算法。

## 验证结果

- 单元测试：OpenSSH Ed25519（无口令及有口令）、RSA、ECDSA，以及传统 PEM RSA（有口令）、ECDSA，均能导入、恢复和完成签名验证。
- PKCS#8：从 Ed25519／RSA／ECDSA 私钥部分提取的公钥与原公钥一致。
- 错误处理：错误／缺失口令、错误公钥、只导入 `.pub` 和损坏文件会报错。
- Android 设备测试两项通过：六种测试文件导入后从加密存储恢复并签名；界面提交不匹配公钥时保留表单且不保存身份，清空公钥后成功自动提取并导入。
- 在电脑生成独立、带口令的临时 Ed25519 私钥，导入模拟器，再通过真实 SSH 登录 Ubuntu；读取服务令牌，健康与会话列表请求成功。
- 已撤销远端临时公钥授权，删除模拟器的测试身份与私钥副本，以及电脑端临时私钥。
- debug 构建、单元测试和 Android lint 通过。系统文件选择入口使用 Android OpenDocument；自动化界面验证使用粘贴入口。

仓库中的 `app/src/test/resources/keys/` 是公开测试数据，不是用户凭据，不用于正常服务器授权。真实 SSH 验证使用独立临时密钥。

## 2026-10-08：密钥类型选择

密钥页明确列出 Ed25519、RSA、ECDSA 和 OpenSSH／PEM 导入支持。“创建密钥”新增类型选择：Ed25519、RSA（3072 位）、ECDSA（NIST P-256），默认仍为 Ed25519。生成在 IO 线程执行，成功后关闭窗口；私钥及算法继续经现有凭据库保存，恢复使用记录的实际算法。已有 RSA 和 ECDSA 私钥可通过“导入已有密钥”选择文件或粘贴内容。

- debug 与设备测试 APK 构建、4 项密钥单元测试通过：三种生成算法的 OpenSSH 公钥编码、存储恢复后的签名，以及现有 OpenSSH／PEM／PKCS#8 导入行为。
- API 36 模拟器 `emulator-5554` 上 3 项设备测试通过：带口令的 RSA PEM 导入与公钥不匹配后修正；六种导入文件的加密保存／恢复／签名；从界面分别创建三种算法并恢复签名。更新了导入测试的入口，使其从右上角菜单进入密钥页。
- 375dp 竖屏已检查新建窗口截图；750dp 横屏深色模式、2 倍系统字体及关闭动画下，三种类型的界面创建与恢复签名测试通过。
