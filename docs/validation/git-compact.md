# 紧凑 Git Graph 验证

日期：2026-09-30。参考用户提供的 VS Code Graph 截图，将手机上的提交行从至少 100dp 调整为常规字体下 48dp，保留触控区域。收起状态只显示单行省略的标题、简短引用标签、相对提交时间及展开指示；作者、提交编号和完整日期放在展开区域。

点击提交在原位置展开，再次点击收起；同一时刻展开一项。展开区域显示完整提交说明、作者、完整时间、短提交 ID、所有引用和变更文件。合并提交可选择父提交并打开相应 Diff，已有会话仍可引用提交到草稿。左侧 DAG 连线随展开区域延伸，分页仍使用原有固定提交集合。返回键先关闭 Diff，再收起详情。

验证：Android debug／测试 APK 构建、单元测试及 lint 通过。相对时间测试覆盖时区换算、分钟、小时、天、月和年。API 36 模拟器的 `CommitGraphTest` 在 360dp 宽度下验证长标题仅一行且确实省略、常规行高 48dp、收起时不显示作者与 ID、展开完整正文、选择第二父提交后传递正确 Diff 参数、引用和再次收起；测试通过。已检查收起与展开截图。

本次调整限于 Android 展示和交互，电脑服务协议与 Git 查询未改变。
