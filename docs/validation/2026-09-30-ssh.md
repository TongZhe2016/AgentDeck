# SSH 与 Android 基础验证

2026-09-30。分支 `feat/agent-workbench`。

- Android Studio 自带 JDK 可启动 Gradle，Wrapper 根据 daemon JVM 配置使用 JDK 25。命令行未设置 Java 时，可用 `JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home" ./gradlew …`。
- 模板及主机／密钥页面 `assembleDebug` 成功；`testDebugUnitTest` 与 `lintDebug` 通过。lint 仍有依赖新版本提示、模板未使用资源和第三方库警告，不代表当前 SSH 链路失败。
- API 36 ARM64 模拟器通过 Keystore AES-GCM 存储、重建存储对象后读取、删除密钥解除主机关联测试。
- 模拟器生成 Ed25519 密钥，通过 OpenSSH 公钥临时授权到本机 Mac，使用 SSHJ 0.40.0 登录成功。服务器身份与本机 `/etc/ssh/ssh_host_ed25519_key.pub` 核对，测试后移除临时授权。
- 本地单元测试验证：私钥序列化后恢复、OpenSSH 公钥解析、对应签名验证、不同消息验证失败。
- 密码认证实现已加入，实际 Mac 密码认证尚未验证。网络切换、进程重启后的 UI 重连及真机后台行为仍待验证。

测试材料和设备地址保留在忽略的 `.local/`，不提交个人公钥授权、服务令牌或私钥。模拟器为当前测试目标；此前 vivo 的 ADB 结果不作为本次功能验收。
