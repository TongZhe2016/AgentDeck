# 执行设置自动保存（2026-10-09）

移除手动“保存设置”按钮。模型、思考强度和权限可以连续调整，关闭面板时一次性应用最终选择，下一轮生效。标题栏提供关闭入口，系统返回、面板外部点击和下滑收起走相同的保存逻辑；未修改时直接关闭，不恢复历史、不提交请求。

保存期间保留面板并显示进度，成功后关闭。失败保留选择，滚动到错误信息，可再次关闭重试，也可放弃更改离开。旋转屏幕时保留面板和选择。加载模型期间禁用选项，避免提交尚未确认的模型组合。
