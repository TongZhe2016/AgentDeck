# 实施路线

## 当前：Android 工程初始化与技术验证

仓库结构、Git 文件和贡献入口已建立。Mac 已安装 Android SDK Platform-Tools 37.0.1；2026-09-29 已完成 vivo V2502A（Android 16／API 36）的 Wi-Fi ADB 配对、自动连接和无线 shell 验证。

Android Studio 已在仓库根目录创建 Kotlin／Compose 工程，应用模块为 `app/`，application ID 为 `com.worldcopy.agentdeck`，当前为模板页面。下一步验证 debug 构建并在这台手机上安装运行，再开展 SSH 与 Agent 模块验证。远端仓库为 `TongZhe2016/AgentDeck`，项目许可证待决定。

## 阶段 0：选底座、跑原型

先比较候选底座的许可证、构建结果与 SSH／Codex 接入成本，再记录选择和固定版本。使用一台真实手机与一台 Linux SSH 主机，跑通历史读取、发送、回复与审批，并验证手机断线后电脑执行持续。

SSH 密钥登录纳入底座验证：手机生成 Ed25519 密钥对、OpenSSH 公钥导出、私钥保存及认证，目标账号的公钥由用户配置。验证结果用于判断 SSH 库是否满足首版需求，详细交互见技术方案第 5.4 节。

Git 原型验证 Changes、单文件 Diff、计数及包含合并分支的 Graph。Claude 历史／恢复和 G2 本地桥接分别做最小验证，记录支持条件或阻塞项。

退出条件：底座有证据支持；主链路可复现；版本和阻塞项有记录。手机 ADB 连通只是开发环境就绪，产品 SSH 链路需独立验证。

## 阶段 1：Codex 与 Git 闭环

实现常驻服务、会话、执行、审批、取消、重连事件恢复，以及 Changes／Diff／Graph。先完成单机，再扩展多主机。

主机管理提供密码／密钥登录选择、手机创建 Ed25519 密钥、按主机关联密钥及公钥复制／分享／导出；完成私钥加密存储、重连认证和密钥删除流程。

退出条件：手机断线不终止受管理执行；重连不重复派发；Git 结果与真实仓库一致。

## 阶段 2：Claude 与已有历史

补齐 Claude、历史分页与搜索、缓存、已停止会话恢复及多主机待处理列表。

退出条件：支持能力与实际版本一致；查看历史不启动执行；恢复保持原生会话身份。

## 阶段 3：日常使用

实现图片、按键语音、通知、分享和缓存清理。验证实际手机上的锁屏、切网、进程重启和耗电；按目标电脑补齐 macOS／Windows。

退出条件：完整 Android 首版的输入、执行、Git 阅读和恢复流程可日常使用，后台条件记录清楚。

## 阶段 4：G2 与后续功能

依据阶段 0 的链路结果实现眼镜摘要、语音和待处理交互。Git 写入、独立 worktree 与其他 Agent 按实际需求另行安排。
