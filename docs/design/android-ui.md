# Android 界面设计

AgentDeck 是手机上的开发工作台，界面优先让用户扫描项目、继续对话、检查 Git 和处理审批。采用 Material 3 原生控件，以标识中的深海蓝与薄荷绿为品牌基础；浅色和深色跟随系统。在右上角菜单可切换系统壁纸配色，选择保存在设备上。

## 来源与取舍

本轮使用 `mobile-android-design` 的 Material 3、触控、安全区和 Compose 布局指导，以及 `ui-ux-pro-max` 的开发工具配色、紧凑密度、触控尺寸和原生组件建议。设计系统检索中的 FAQ 网站布局不适用本产品，导航和页面结构采用 Android 原生工作台布局；不保存该检索结果作为设计规范。

## 视觉与布局

- 配色集中在 `ui/theme/`；页面使用语义颜色。深色增删行分别使用 primary／error，避免固定的深绿色在暗色背景上难以阅读。
- 页面边距 20dp，卡片内边距 16dp，间距以 4／8dp 为基础。标题突出名称，路径和来源用次级文字。代码与公钥使用等宽字体。
- 图标采用本仓库绘制的 24dp 线性矢量图；独立图标按钮由原生 IconButton 提供至少 48dp 的触控目标。
- 手机采用项目／密钥／待处理三项底部导航；可用宽度达到 600dp 时使用侧边 NavigationRail。键盘显示时收起手机底部导航，内容消费 Scaffold 内边距，输入区处理 IME 安全区。
- 依照系统字号排版，操作集合使用 FlowRow，在窄屏和大字体下换行。保留原生 ripple，加载动画仅在连接与读取期间显示。

## 页面

项目页采用“主机 → 项目 → 对话”的两层折叠，主机与项目默认收起。一级主机卡片显示主机名、项目数和对话总数；二级项目卡片缩进 16dp，显示文件夹名、对话数与完整路径；对话缩进 32dp。收起主机同时收起其项目，返回首页时两层恢复折叠。按主机 ID 与完整路径区分同名项目。主机行右侧在连接／同步时显示转圈，失败或等待核对身份时显示警告三角形，正常时显示展开箭头；状态逐台更新。展开主机可查看错误、最近同步时间并重试或取消读取，不再设独立的“主机同步”区域。没有项目缓存的主机也显示状态。

打开 App 或回到前台时自动连接并同步项目，已在线的主机复用连接刷新会话。同步时可展开主机和项目查看列表，对话入口在同步完成后可用。首次连接或身份变化的提示按主机依次显示，确认后继续同步；失败主机保留缓存，其他主机继续同步。

项目页顶部保留绿色“添加主机”，位于“同步项目”左侧；窄屏或大字号下按此顺序换行。单击主机展开项目，长按主机打开原生底部操作菜单，显示主机名与 SSH 地址，并提供进入工作台、连接、重连、编辑、克隆和删除。菜单直接完整展开，内容超出屏幕时可滚动，按钮至少 48dp，主机行提供明确的无障碍长按标签；页面显示长按提示。连接会同步项目，重连先关闭旧 SSH／服务连接再重新建立；编辑／克隆沿用主机表单，删除沿用确认提示。密钥卡片优先显示名称、算法和使用主机数量，公钥按需展开后复制、分享或导出。

工作台保留会话／Changes／Graph。聊天使用独立输入区，附件菜单承载图片、拍照和转写，录音进行中显示停止入口。文件差异进入全屏阅读，增删颜色按主题适配；Git 提交仍为单行标题、相对时间与点击展开详情。

进入工作台后只显示主机工具栏，为横屏聊天保留阅读空间；返回首页可访问全局设置和后台同步。工作台标签保持单行，在大字号下横向滚动。

待处理页显示数量和明确的空状态，底部导航带待处理数量标记。全局后台同步、缓存清理与配色入口保持可访问。

验证记录见 `docs/validation/android-ui.md`。
